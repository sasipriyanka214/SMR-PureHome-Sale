SMR NANO UPDATE

Changes included:
1. Electronics category is replaced by Nano.
2. Nano products:
   - Envy 1000 Deo Nano Beats
   - Envy 1000 Deo Nano Blaze
   - Envy 1000 Deo Nano Club
3. Nano product master:
   - GM/ML: 25 GM/30 ML
   - MRP: 75
   - Case Size: 144
   - Rate: 51.99
4. Primary Order:
   - Nano quantity is 12, 24, 36, 48... only.
   - +12 and -12 controls are added.
   - User cannot edit Scheme.
   - Scheme is calculated automatically from Admin Scheme Adjustment and quantity/case size.
5. Nano uses the existing Admin ENVY scheme category:
   Envy Deo Nano 25Gm/30ml
   Trade Promotion: 30%
   Slab 1: 33% on 1 CS
   Slab 2: 34% on 2 CS
   Slab 3: 35% on 3 CS
   Since Nano case size is 144, these thresholds are:
   144, 288 and 432 pieces.
6. Existing Electronics products are migrated to Nano where possible so existing
   product references are not unnecessarily broken.
